## 方法论（心智模型）
- **渐进超负荷（progressive overload）**：体能提升的唯一根本——负荷（重量/
  次数/密度/强度）须随适应渐进增加，否则停滞。
- **专项性（SAID）**：训练适应高度特异于动作模式、收缩速度、肌群、能量系统；
  想跑得快就练"跑相关的"力量（单腿、爆发、向心-离心），而非孤立器械。
- **个体化 + 变化**：同一处方对不同人效果不同；长期不变会平台，需周期性变化
  刺激（variation）同时保留专项性。
- **恢复是处方的一部分**：适应发生在恢复期，不是训练当时。

## 核心流程

### 1. 训练目标 → 负荷参数表（核心处方表）
| 目标 | 强度 %1RM | 次数/组 | 组数 | 组间休息 | 节奏要点 |
|------|-----------|---------|------|----------|----------|
| 最大力量 Maximum Strength | 80–95% | 1–5 | 2–6 | 2–5 min | 控制向心，可控离心 |
| 爆发力 Power | 30–60% 1RM（或 10% 体重抛掷） | 1–5 | 3–5 | 2–5 min | 最大动作速度 |
| 肌肉肥大 Hypertrophy | 67–85% | 6–12 | 3–6 | 30s–1.5 min | 中速、肌肉紧张时间足 |
| 肌肉耐力 Muscular Endurance | <67% | >12 | 2–3 | <30s | 短休维持代谢压力 |

- 跑者力量目标通常是**最大力量（神经驱动）+ 耐力（12–16 次）**的组合，
  而非健美式肥大（见 injuryfree.md：跑者练 12–16 次重复）。

### 2. 单次训练课动作编排顺序
1. **爆发力/奥林匹克举重类**（高神经需求，最优先）：高翻、抓举、药球抛掷等。
2. **多关节主要动作（核心/primary）**：深蹲、硬拉、卧推、引体——大重量复合。
3. **辅助/单关节（assistance）**：臂屈伸、侧平举、腿屈伸等。
4. **核心/躯干稳定**：最后或穿插。
- 原则：**高难度/高神经/大重量优先**，疲劳后再做孤立小肌群。
- 跑者专项化：把"单腿"动作（单腿硬拉、保加利亚剪蹲、单腿臀桥）放在主要复合
  动作之后作为专项补充（呼应 injuryfree.md 力量阶梯）。

### 3. 周期化模式（与 periodization.md 衔接）
- **线性周期（classic/linear）**：数周/数月内逐步加量减重（强度↑次数↓），适合
  打基础期、新手。
- **每日波动周期（DUP, daily undulating）**：一周内不同天用不同负荷/次数组合
  （如 周一 5RM、周三 10RM、周五 15RM），适合进阶者维持多能力。
- **每周波动**：以周为单位切换重点。
- 选择：新手/基础 → 线性；有经验 → DUP/波动避免平台。

### 4. 进阶规则
- **2-for-2 规则**：某动作连续 2 次训练都能比目标次数**多完成 2 次** → 加量
  （约 +2–10% 重量）。
- 负荷进阶幅度：新手可稍快，老手小幅渐进，避免关节/肌腱过载。

## 决策规则
- IF 目标=最大力量 → 80–95% 1RM、1–5 次、休 2–5 min；IF 目标=爆发 → 轻重量
  最大速度（30–60%）或抛掷。
- IF 目标=跑者实用力量 → 主练最大力量神经驱动 + 12–16 次耐力，避免纯肥大大重量。
- IF 排课顺序 → 爆发/复合大重量在前，单关节/核心在后。
- IF 进阶判断 → 用 2-for-2 规则加量，不靠感觉硬加。
- IF 周期选择 → 新手线性、进阶 DUP/波动。
- IF 跑者力量日 → 与跑步日分开（耐力↔力量相互拮抗，见 injuryfree.md）。

## 反模式（不要做）
- 孤立小肌群（弯举）放在深蹲/硬拉前——神经疲劳后大重量动作变形、易伤。
- 只练肥大（8–12 次中重量）当作"跑者力量"——跑者需神经力量+耐力，非肌肥大。
- 长期不变处方——平台；也不宜频繁大变——丢失专项性。
- 重量加得太快忽略 2-for-2——肌腱/关节跟不上肌肉，易过劳。

## 速查表（决策用）
- 处方表：力量 80–95%/1–5次/2–6组/休2–5min；爆发 30–60%/1–5次/最大速度；
  肥大 67–85%/6–12次/3–6组/休30s–1.5min；耐力 <67%/>12次/2–3组/休<30s。
- 课顺序：爆发/奥举 → 多关节复合 → 辅助单关节 → 核心。
- 周期：新手线性、进阶 DUP；进阶用 2-for-2 加量。
- 跑者：最大力量+耐力(12–16次)、单腿专项、与跑分日。
