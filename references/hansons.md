## 方法论（心智模型）
- **累积疲劳（cumulative fatigue）模型**：传统计划靠"一次超长 LSD（32km+）"
  制造刺激；汉森认为更聪明的是**把压力均匀铺在一周多次质量课上**，让身体在全周
  持续处于"未完全恢复"的疲劳态，从而在不堆单次超长跑的前提下逼近比赛负荷。
- **没有"垃圾跑量"与"恢复日"的对立**：一周 6 跑，3 个质量日 + 3 个轻松日，
  轻松日是用来吸收质量日刺激的，不是可有可无。
- **长限顶（cap the long run）**：周最长跑**不超过约 16 英里（~26km）**，
  且占周跑量 **≤25–30%**。理由是周内的速度/力量课已造成疲劳，长跑去更长反而
  拖慢恢复、挤占下周质量课。
- **目标配速内嵌**：马拉松配速（MP）训练贯穿中后期，而非只留到赛前。

## 核心流程

### 1. 一周结构（6 跑 / 马拉松专项阶段）
| 日 | 内容 | 性质 |
|----|------|------|
| 周一 | 轻松跑 | 恢复 |
| 周二 | **速度日（Speed）**：400m/800m 间歇，配速≈5K–10K 比赛配 | 质量（神经/速度） |
| 周三 | 轻松跑 | 恢复 |
| 周四 | **力量日（Strength）**：节奏跑 / 马拉松配速（MP）持续努力 | 质量（耐力/MP） |
| 周五 | 轻松跑 | 恢复 |
| 周六 | 轻松跑 | 恢复 |
| 周日 | **长距离（Long）**：≤16mi / ~26km，配速接近或略快于 MP | 质量（耐力顶） |

- 三个质量日 = Speed + Strength + Long，各管一个能量系统；其余为轻松跑。
- 强度排序参考（对高手最准）：Speed 最快（5K–10K 配），Strength 偏 MP/节奏，
  Long 控制在 MP 附近或稍慢。

### 2. 周期划分（以 18 周专项为例）
- **基础/打底期（前置）**：先建有氧底，再进专项。无规律跑底子不进 18 周计划。
- **18 周专项**常分三段（每段 ~6 周）：
  - 第 1 段（Form/打形）：建立节奏与配速感，强度渐进。
  - 第 2 段（Fitness/体能）：速度与力量课最密集、最难。
  - 第 3 段（Focus + Taper/聚焦减量）：降量保强度，赛前 3 周减量。
- **减量（Taper）**：约 3 周，周跑量逐周降（如 100%→75%→50%），但**保留质量
  课的配速强度**，只砍量，让身体超量恢复。

### 3. 关键参数（经验值）
- 周跑量分级随水平：初学者/回归者低起点，精英可达 70+ 英里/周。
- 长跑占比：**≤25–30% 周跑量**（所以 60mi 周 → 长限约 16mi）。
- 速度日：间歇总量通常 5–10km 等效；力量日：节奏/MP 累计 20–40min+。
- 轻松日配速：明显慢于 MP，能对话、不累积额外疲劳。

## 决策规则
- IF 设计马拉松计划且跑者能每周 6 跑 → 用「3 质量日（Speed/Strength/Long）+3 轻松」。
- IF 排长限 → 封顶 ~26km 且 ≤ 周跑量 30%，别学 32km+ 超长 LSD。
- IF 进入专项中后期 → MP 训练要落到节奏/力量课，而非只赛前突击。
- IF 赛前 3 周 → 减总量、保强度（质量课配速不退）。
- IF 跑者周跑量低/新手 → 先基础期，别直接上 3 质量日高密度。

## 反模式（不要做）
- 照搬"一次 32km LSD"——汉森体系用周疲劳替代单次超长，强行加长反而伤恢复。
- 长限超过周跑量 30%——挤压下周质量课，违背累积疲劳逻辑。
- 减量期把强度也砍了——减量只降量，配速强度要留。
- 轻松日跑成"中强度"——轻松日不轻松就失去吸收刺激的作用。

## 速查表（决策用）
- 周结构：Speed（5K–10K 配间歇）+ Strength（MP/节奏）+ Long（≤26km, MP 附近）+ 3 轻松。
- 长限 ≤ 周跑量 30%；18 周 = 基础→专项（3×6 周）→ 3 周 Taper。
- Taper：量 100%→75%→50%，强度不退。
