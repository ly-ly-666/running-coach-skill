# 周期训练理论与方法（Bompa 邦帕）— 蒸馏稿

> 来源：图德·O.邦帕《周期训练理论与方法（第6版）》。
> 本稿覆盖**年/赛季尺度的计划结构方法论**：周期类型选择、阶段划分、
> 身体运动能力的依序周期安排、小周期/大周期构建、减负荷与过渡期。
> 与 Daniels（单周强度分区）互补：Daniels 管"一周内怎么练"，本稿管
> "一年怎么排"。本稿**不含具体配速/组数计算器**，只给决策框架。

## 方法论（心智模型）
- **训练是"适应管理系统"**：由「高强度刺激期（引发形态/功能适应）」+
  「轻松/休息期（恢复并超量补偿）」交替组成。计划的目的就是**在正确
  的时间点把竞技状态（peak）推到最高**，而不是全年都高强度。
- **阶段而非均一**：年度计划被切成 准备期 → 比赛期 → 过渡期 三个主阶段，
  准备期再分 一般准备期 + 专项准备期。每个子阶段有唯一目标，且目标必须
  指向年度总目标。
- **能力依序发展（关键原则）**：对速度/爆发力类项目，身体运动能力的
  周期顺序是 **生理适应 → 最大力量 → 爆发力 → 灵敏性**。先有最大力量，
  才谈得上爆发力（爆发力 = 力量 × 速度）；灵敏性在最大力量提高后才明显
  提升，而不是反过来。
- **周期 ≠ 线性/波动负荷**：线性/波动是"负荷安排的方法"，不是周期本身。
  周期是基于"阶段"的依序安排。纯线性渐增负荷（一直加量）正是健美运动员
  过度训练的主因之一——生物系统需要"刺激-恢复-超量补偿"的波峰波谷。
- **计划要灵活、可调整**：初始计划根据测试结果、训练进度、比赛结果
  微调甚至重构；但结构（阶段顺序、减负荷时机）要稳定。

## 核心流程

### 1. 选择周期类型（按运动员水平 + 比赛日程）
| 类型 | 适用对象 | 关键特征 |
|------|----------|----------|
| 单周期 | 初级/青少年；季节性或耐力主导项目（长跑、北欧滑雪、赛艇、自行车） | 长准备期，全年 1 个比赛高峰 |
| 双周期 | 有全国赛资格的高水平/精英运动员 | 2 个独立赛季（如田径室内+室外），准备期仍尽可能长 |
| 三周期 | 高级/国际水准，年度 3 个主要比赛（全国赛/资格赛/国际赛） | 基础扎实，能承受 3+ 个高峰 |
| 多周期 | 良好训练基础（多年）、高水平、比赛密集者（如网球） | 压缩每周期周数，尤其准备期；**不建议青少年** |

- 决定因素：运动员每年参赛日程 + 个人特征 + 项目专项特征。
- 青少年/低水平者一律从**单周期**起步，利用长准备期打基础、避比赛压力。

### 2. 年度三阶段 + 子阶段
- **准备期（最重要）**：建立身体/技术/心理基础，决定比赛期成败。
  目标 = 提升一般身体能力 + 专项身体能力 + 心理素质 + 技术 + 基本战术 +
  专项理论 + 个性化营养计划。
  - 时长：个人有氧耐力项目（马拉松/铁三/北欧滑雪）准备期 ≈ 比赛期 **2 倍**；
    团体项目较短但不 < 1.5–2 月（年轻者更长）；国际级可能仅 3–4 周。
  - **一般准备期**：重点建身体基础。量高、强度次要（强度训练量 < 总训练量
    10%，尤新手）；此阶段**不宜比赛**（疲劳→受伤/技术波动）。耐力项目把
    总时 60–70% 投有氧耐力；力量/速度项目多投生理适应+最大力量。
  - **专项准备期**：转向专项方式提升所需能力。一般准备期约占准备期 60% 时间。
- **比赛期**：完善所有因素，在主要比赛拿名次。
  - 量渐减、强度渐增（速度/爆发力/最大力量项目：强度急增同时量急减；
    耐力项目：量维持或略低）。
  - 60–70% 投专项训练，其余非专项（积极性休息/游戏）。
  - 时长取决于计划类型：集体项目常见 3–5 月；个人项目更自由。
  - 达最高表现平均需 **~7 次比赛**；结构因素 = 比赛数量/间隔/资格赛时长/
    主要赛前专项准备时间。
- **过渡期**：主要比赛后立即开始，持续 **2–4 周**。
  - 第 1 周可消极（受伤时）或积极休息；第 2–4 小周期量/强度维持低位或略增。
  - 完全停训 → 前期适应急剧丢失，下个准备期要重头来；**积极性休息**（其他
    项目或低量低强专项，且符合项目能量代谢特征，如自行车→越野滑雪/跑步、
    排球→篮球）可把丢失降到最小。停训 2–3 周力量/爆发力仍稳定。

### 3. 身体运动能力的依序周期安排（速度/爆发力类）
顺序固定：**生理适应 → 最大力量 → 爆发力 → 灵敏性**
- **生理适应阶段**（一般准备期早期）：刺激大部分肌群（含稳定肌）；
  提高短时运动能力；学力量练习基本技术。负荷特征 低强度（~65% 1RM）、
  多次数（~8–20 次，2–3 组）。新手需 ≥2 周，有经验者 1–2 周；青少年/
  无经验者更长，职业集体项目 1–2 周足够。
- **最大力量阶段**：建立在生理适应上，提升爆发力必需的神经肌肉因素。
  最大力量阶段持续 1–6 个月（依项目）。
- **爆发力 + 灵敏性阶段**：最大力量阶段用 ~90% 1RM 已充分募集快肌纤维，
  下一阶段快速用力/变向（加速减速）。训练 **2–6 周**（取决于最大力量阶段
  时长）即明显提升。
- **耐力/无氧耐力**：单周期耐力提升 3 阶段 = 有氧耐力 → 有氧+专项耐力 →
  专项耐力（机能增强）。有氧耐力是过渡期+准备期早期（1–3 月）重点。
  速度是无氧耐力的前置（神经肌肉角度）；提乳酸耐受前先提有氧能力。
  最大速度训练对集体项目有**预防腘绳肌受伤**作用。

### 4. 大周期（中周期，~4–12 周）
- 小周期 = 即将到来的一周；大周期 = 未来几周的一般结构。
- **准备期大周期**用「逐级渐增负荷」：最常用 **3:1 模式**（契合身体自然周期）
  = 3 个负荷递增小周期 + 1 个减负荷/再生小周期。若第 3 周疲劳过高，第 4 周
  负荷大降或加恢复周 → 4:1。也可用 2:1（前 2 周递增，末周减负荷）。
- **比赛期大周期**：3–6 个 1 周小周期，末期通常排减负荷小周期后接比赛。
  一个月内多场比赛（≤8 场，集体项目常见）时，只盯**最重要一场**，小比赛
  当作训练反馈。

### 5. 小周期（1 周）构建与分类
- 古希腊"集群系统"原型：第1天短时活力 → 第2天高强度 → 第3天恢复 →
  第4天中等，循环。
- **顺序原则**：技术战术 → 速度/灵敏/爆发力 → 力量 → 专项耐力。
  一次课的疲劳显著影响下一课，故顺序要把疲劳积累考虑进去。
- **频率参考**：专项耐力次最大强度每周 2 次够；比赛期最大强度专项耐力每周
  2 次，其余低强度。维持力量/柔韧/速度每周 2–3 次；快速伸缩复合/速度/灵敏
  最佳 2–3 天/周。**最大负荷课每周 ≤2 次**，其余低强度或积极性休息。
- **渐增负荷**：小周期通常 1 个峰值（在周中），偶尔 2 个峰值（前 1–2 天恢复）。
  高原/跨 >6h 时差 → 加无峰值适应周；湿热气候 → 把峰值放在一周精力旺时。
- **按目标分 4 类小周期**：
  - **提升小周期**：准备期，含 1–3 个中/高负荷峰值，变换能量系统。
  - **恢复再生小周期**：消除疲劳积累，负荷极低（降强度/减量或双降）；用于
    准备期末、比赛期初、过渡期。
  - **调整/减负荷小周期**：每个中周期末期，最重要比赛前通常**连续 2 个**。
    降周量 41–60%+，维持或减强度 10–30%，引发超量补偿、降过度训练风险。
  - **比赛小周期**：顺序由赛程定。每周 1 赛 → 1–3 天休息恢复，力量爆发力放
    周中，赛前 2 天减负荷。一周双赛（集体）→ 周一再生、周二战术(为周三赛)、
    周四再生、周五是唯一高负荷(力量爆发力中低总量, 4–6 个动作)、周六减负荷、
    周日赛。赛会制(连续>2天) → 赛前 2 天(周四五)减负荷，周二最高负荷后渐降；
    每比赛日早晨排低强度再生(促乳酸清除/抑制中枢神经/增副交感/降酸痛)，并
    在活动后补够碳水恢复糖原。

### 6. 长期计划（4–8 年）
- 运动员需 4–8 年专门训练达最高水平。阶段：开始 → 竞技形成 → 专项化 →
  高运动表现水平。早期就要定长期模式，定期测试、监测进度并调整。

## 决策规则
- IF 青少年/低水平/耐力主导 → 用**单周期**，长准备期打基础，避比赛压力。
- IF 年度有 2 个独立赛季 → 用**双周期**（如田径室内+室外）。
- IF 年度有 3 个主要比赛 → 用**三周期**，最重要比赛放在最后周期。
- IF 设计速度/爆发力项目年度 → 能力顺序固定 生理适应→最大力量→爆发力→
  灵敏性，不可颠倒。
- IF 排准备期 → 一般准备期量高、强度<10%总训练量，此阶段不比赛。
- IF 最重要比赛前 → 连续排 **2 个减负荷小周期**（降量 41–60%、强度±）。
- IF 比赛期 → 量渐减、强度渐增；耐力项目量维持，速度/力量项目量急减。
- IF 过渡期 → 用积极性休息（符合项目能量特征的其他活动），不全停训。
- IF 小周期设计 → 最大负荷课每周 ≤2 次；强度区间从极高(~90–100%)到恢复日。

## 反模式（不要做）
- 把"周期"和"线性/波动负荷"混为一谈——纯线性一直加量是过度训练温床。
- 在一般准备期安排比赛（疲劳累积→受伤、技术波动、战术能力下降）。
- 颠倒能力顺序：没打好最大力量就猛练灵敏/爆发力（灵敏性不源于速度）。
- 过渡期完全停训——前期适应急剧丢失，下个准备期要从头再来。
- 多峰（多周期）计划用于青少年——易造成各种损伤（尤其足球/网球）。
- 小周期过度复杂：专家推测有 ≥70 种结构，但教练应抓常见结构再按需调，
  计划要简单、具体到日期/目标/课内容。
- "强度第一/没有痛苦就没有收获"——应以体育科学原则为依据设计合理训练课。

## 速查表（决策用）
- 周期类型：单(1峰/新手/耐力) · 双(2赛季) · 三(3大赛) · 多(密集/网球/勿青少年)。
- 年度三阶段：准备期(一般+专项准备) → 比赛期 → 过渡期(2–4周)。
- 能力顺序：生理适应 → 最大力量 → 爆发力 → 灵敏性。
- 大周期负荷：3:1 最常用（3增1减），疲劳高则改 4:1 或 2:1。
- 小周期 4 类：提升 / 比赛 / 恢复再生 / 减负荷（重要赛前连排 2 个）。
- 减负荷：降量 41–60%+、强度±10–30%，引发超量补偿。
- 一般准备期：强度训练量 < 总训练量 10%；耐力项目有氧占 60–70% 总时间。
- 过渡期：积极性休息保适应；停训 2–3 周力量/爆发力仍稳。
