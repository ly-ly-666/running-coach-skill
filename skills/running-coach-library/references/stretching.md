## 方法论（心智模型）
- **拉伸有"急性"与"慢性"两种收益，不能混为一谈**。急性（单次）拉伸主要
  改善关节活动度、抑制神经兴奋性，但会暂时降低最大力量/爆发/耐力；慢性
  （每周 3–4 天、坚持数周）拉伸才真正提升柔韧性、力量与耐力，并降低久
  坐/老化带来的僵硬。
- **时机决定类型**：运动前用动态拉伸（升体温、激活神经、模拟动作）；
  运动后（肌肉已暖）用静态拉伸做"永久性"柔韧增益。把静态拉伸放在运动前
  反而可能削弱表现，>30 秒的静态热身负面影响最明显。
- **强度由"痛感"而非蛮力控制**：用 0–10 痛感量表，拉伸到"轻微不适"即可，
  绝不拉到剧痛。更重的拉伸（7–10）对柔韧/力量增益更有效，但必须循序渐进。
- **每块肌肉要用"反向运动"去拉**：要拉长某肌，动作方向须与该肌功能相反；
  肌肉越紧，同时做的反向动作越少，随放松再逐步加量。

## 核心流程

### 1. 拉伸类型与时机
| 类型 | 机制 | 何时用 | 注意 |
|------|------|--------|------|
| 动态拉伸 dynamic | 摆动/夸张动作，动量带过活动范围，激活本体感受器、升温 | **运动前热身**（10–15 分钟） | 不弹跳、不超活动范围 |
| 静态拉伸 static | 保持某一姿势一定时间 | **运动后放松**（永久柔韧增益） | 也可日常做；运动前只做短的 |
| PNF（本体感觉神经肌肉促进） | 先等长收缩目标肌→放松→更深拉伸 | 针对性提升活动范围、突破紧绷 | 最好有人辅助 |
| 弹震式 ballistic | 快速弹跳 | **不推荐**（易触发牵张反射） | 书未证实致伤，但风险高、收益无优势 |

- 决策口诀：**前动态、后静态；要突破用 PNF；弹震式尽量不用**。

### 2. 静态拉伸操作规范
- **保持时长**：初级 5–10s → 中级 15–20s → 高级 25–30s → 专家 30–40s。
  日常改善柔韧建议单肌群累计 ≥15s。
- **强度（0–10 痛感量表）**：1–3 轻微、4–6 中度、7–10 重度。
  常规用 1–6；进阶周可用 7–10（重度）2–3 次/周，配合轻度日。
- **组数与休息**：重复 2–5 次/肌群（日常 2–4 即可）；组间休 5–30s（按级别）。
- **频率**：初级 2–3 次/周，中/高/专家 4–5 次/周；重度拉伸周之间插入轻拉伸日。
- **进阶**：每级至少坚持 4 周再升下级；从轻微拉伸起步当作热身，逐步建立耐受。
- **呼吸/放松**：缓慢呼气有助于放松、借抑制反射加深拉伸；不要憋气、不要对抗。
- **体位细节**：躺/坐类拉伸身下垫**牢固**软垫（太软会削弱效果）；微调手/躯干
  角度可改变目标肌，找到紧绷点。

### 3. 跑者动态拉伸清单（运动前，10–20 次/动作或 10–15 分钟）
按书第 8 章 + 跑步专项编排，动作须模仿跑步模式、缓慢起步逐步加速：
- **动态髋屈肌和伸肌拉伸**（前后摆腿）→ 激活股四头/腘绳/臀。
- **动态髋内收肌和外展肌拉伸**（左右侧摆腿）→ 开髋、防腹股沟紧。
- **动态髋外旋/内旋肌拉伸**（髋关节画圈）→ 深度髋外旋肌（跑坡易酸）。
- **动态站姿膝屈肌拉伸**（体前屈触膝上下摆）→ 腘绳肌+腓肠肌。
- **动态跖屈肌拉伸**（台阶边缘上下落踵）→ 小腿后侧，跑前跑后皆宜。
- **动态躯干侧屈 / 回旋**（体侧摆、转体摆臂）→ 核心稳定肌。
- **跑步专项补充**：高抬腿、后踢腿（heel-to-butt）、行走弓步、A 字跳——
  本质即书中所讲的"模拟运动模式的动态拉伸"，放在摆腿之后做。
- 规则：同位置或移动一段距离均可；每次重复都用正确技术（像真跑一样）；
  全程肌肉收缩、完全可控、**禁止弹跳**。

### 4. PNF 流程（收缩–放松法）
1. 将目标肌置于拉伸位，静态轻拉至"轻微 tension"。
2. **等长收缩**该肌对抗阻力（同伴手/自身/带子）约 5–10 秒，不移动关节。
3. 放松 2–3 秒，借高尔基腱器官（GTO）抑制反射，立即**加深静态拉伸**。
4. 重复 2–4 轮；同一肌群单侧做完换另一侧。
- 适用：久紧、活动度卡住的部位（髋外旋肌、腘绳肌、小腿）。最佳有人辅助。

### 5. 跑者重点部位拉伸速查表（region → 静态代表动作 + 目标）
| 部位 | 代表静态拉伸 | 主要目标肌 |
|------|--------------|-----------|
| 颈部 | 颈屈/伸肌拉伸 | 颈屈肌、颈伸肌 |
| 肩背胸 | 肩屈肌拉伸（开胸）/ 肩伸肌内收肌拉伸（夹背） | 胸大肌、背阔肌、菱形肌 |
| 手臂手腕 | 肱三头肌拉伸 / 腕屈伸肌拉伸 | 肱三头、前臂屈伸肌 |
| 躯干下部 | 仰卧/俯卧躯干屈肌、坐姿躯干伸肌、侧屈肌 | 腹直肌、竖脊肌、腰方肌 |
| 髋部 | 坐姿/站姿髋外旋肌拉伸、侧弓步髋内收肌拉伸 | 臀肌、梨状肌、内收肌 |
| 膝大腿 | 膝屈肌拉伸（腘绳）、膝伸肌拉伸（股四头） | 腘绳肌、股四头肌 |
| 足部小腿 | 跖屈肌拉伸（靠墙/台阶）、趾伸/屈肌拉伸 | 腓肠肌、比目鱼肌、足底肌 |

- 跑者高频紧张区：**髋屈肌（久坐/前倾跑姿）、腘绳肌、小腿三头肌、髋外旋肌
  （跑坡/变向易酸）**——优先安排。

### 6. 如何定制计划
- **先评估**：自测/询问哪些部位紧、哪些动作受限，针对性加量。
- **覆盖原则**：包含全部主要肌群；每种关节运动至少一次拉伸；大部分用静态。
- **日程模板**：
  - 运动前 → 仅轻微动态拉伸热身（5–15 分钟）。
  - 运动后 → 轻度到中度静态拉伸做舒缓（主柔韧增益）。
  - 训练后酸痛 → 只做 2–3 次**轻微**拉伸，每次 5–10s，组间休 5–10s。
  - 酸痛持续多日 → 继续轻微拉伸 2–3 次/日，5–10s。
- **强度进阶**：从轻微（1–3）起步当热身，耐受建立后再升中级/高级；
  重度（7–10）周与轻度日穿插，避免长期过度使用致疲劳虚弱。
- **跑步专项**：以"中等柔韧"为最低门槛；动态作赛前、静态作赛后，按上表选位。

## 决策规则
- IF 运动即将开始 → 做动态拉伸（10–15 分钟/10–20 次），**不做**长时间静态。
- IF 运动刚结束 → 做静态拉伸，单肌群保持 ≥15s（紧处可到 25–30s），2–4 组。
- IF 某部位长期卡住/紧绷 → 用 PNF 收缩–放松，2–4 轮，最好有人辅助。
- IF 拉伸强度选择 → 用 0–10 痛感：日常 1–6；进阶周 7–10 仅 2–3 次/周且配轻度日。
- IF 训练后肌肉酸痛 → 仅轻微拉伸 2–3 次×5–10s，组间休 5–10s；持续则每日轻拉。
- IF 初学者/久未拉伸 → 从初级计划起（hold 5–10s、重复 2–3、2–3 次/周），≥4 周再进阶。
- IF 要永久提升柔韧 → 必须坚持慢性计划（每周 4–5 次、坚持数周），非单次拉伸可得。
- IF 跑者编排 → 优先髋屈肌、腘绳肌、小腿三头、髋外旋肌；前动态后静态。

## 反模式（不要做）
- 运动前做 >30 秒静态拉伸当热身——会削弱最大力量、爆发与跑速。
- 用弹震式（快速弹跳）拉伸——易触发牵张反射、风险高、无收益优势。
- 拉到"剧痛"才罢休——超出 7–10 重度区间易伤；拉伸是"舒服的不适"。
- 只拉下身、忽略上半身与核心——应按"全主要肌群+每关节运动至少一次"覆盖。
- 酸痛时还做重度拉伸或硬扛——应只做轻微短拉，身体信号说放慢就放慢。
- 一上来就抄高级计划——未建立耐受直接重度拉伸易疲劳虚弱，须逐级进阶。
- 垫子过软做坐/躺拉伸——软垫削弱拉伸效果，用牢固垫。

## 速查表（决策用）
- 类型时机：前动态（热身/升温）、后静态（柔韧增益）、突破用 PNF、避弹震。
- 静态分级：初级 5–10s×2–3（2–3次/周）→ 中级 15–20s×3–4（4–5次/周）
  → 高级 25–30s×5 → 专家 30–40s×5；每级 ≥4 周再升。
- 痛感量表：1–3 轻微 / 4–6 中度 / 7–10 重度；更重更有效，但须渐进。
- 动态要点：10–15 分钟或 10–20 次/动作、不弹跳、模仿跑姿、缓慢加速。
- 跑者必拉：髋屈肌、腘绳肌、小腿三头、髋外旋肌（前动态后静态）。
- 酸痛处理：仅轻微 2–3×5–10s，组间休 5–10s；持续多日则每日轻拉。
