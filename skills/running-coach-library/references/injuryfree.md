# 无伤跑法（郑家轩 & 戴剑松）— 蒸馏稿

> 来源：《无伤跑法》（跑步学院/慧跑）。本稿只覆盖**代码无法表达的跑姿、力量、伤痛处理、
> 训练方法与马拉松参赛方法论**，定位为大众科普向、伤痛预防向，与 daniels.md（竞技化
> 强度分区/周期化）互补：daniels 解决"怎么练更快"，本稿解决"怎么练不伤、伤了怎么治本"。
> 来源章节映射见文末。

## 方法论（心智模型）
- **跑步伤痛的头号诱因是"大步幅 + 慢步频"**，而非某一种着地部位。着地方式（前掌/全脚掌/
  脚跟）本身不是问题，关键是**着地点靠近重心 + 着地时膝关节微屈缓冲**。哈佛研究：着地"轻"
  （低垂直冲击速率）比着地"哪里"更重要——跺脚式重着地的人伤痛率显著更高。
- **信封效应（Envelope Theory）**：身体承受运动负荷的能力有上限（"信封"）。循序渐进负荷让
  信封变大、能跑更多；一次过量（如平时只跑 10km 贸然跑全马）或跑量猛增会撑破信封→不可逆
  损伤。受伤后能力下降（信封变小），更易伤，形成恶性循环。
- **伤痛要"治本"而非"治标"**：休息/药物/护具只能缓解，根因是力量不足、柔韧差、跑姿错。
  反复出现的根因规律 = **臀中肌弱 → 骨盆/膝不稳 → 膝内扣 → 膝痛**；以及**组织"不够软"**
  （肌肉紧张僵硬→缓冲差→劳损）。
- **跑步不"掉肌肉"，只改变肌肉类型**：耐力训练发达慢肌（不粗壮但耐疲劳）；力量训练发达快
  肌。大众跑者需要的是肌肉耐力（12–16 次重复），而非大重量。
- **速度越慢，越要把跑姿/力量做对**：多数伤痛来自"慢不下来、快不上去"的中等强度陷阱与跑量
  冒进，而非速度本身。

## 核心流程

### 1. 无伤跑姿要点（动态、随配速变化）
- **合理跑姿四要素**：①头正直、挺胸收腹微前倾（约 15°）；②以肩为轴前后摆臂，不越身体中线；
  ③着地点靠近臀部正下方（重心投影点略靠前一点，非正下方也非远离）；④步频 170–180 步/分最佳。
- **着地方式随配速自适应**（不要僵化模仿）：慢速（5:00 及更慢）→ 全脚掌外侧先着地再快速过渡
  全脚掌，最护膝且不致小腿紧张；快速（4:00 及更快）→ 前脚掌外侧着地更有优势（脚踝缓冲好、
  触地时间短）。脚跟着地本身不算错，但触地瞬间有无法回避的峰值应力，应避免"脚跟远靠前 +
  膝伸直锁死"的甩小腿跑法。
- **着地位置 > 着地方式**：无论快慢，着地点均在重心略靠前，着地瞬间膝关节保持约 160–163°
  微屈，着地后积极下压至约 136° 缓冲并储能；切忌膝伸直锁死。
- **提高步频是减小步幅的第一手段**：步频 <170 通常意味着步幅过大；用节拍器设 180 步/分跟跑。
  松软着地 + 快步频能同时降低膝/髋冲击与水平剪切力。

### 2. 跑者力量训练框架（核心→臀中肌→下肢→小腿→爆发力）
**核心（WHY：躯干稳定是上下肢发力支点，核心弱→躯干乱扭、骨盆上下摆、后仰/撅屁股跑）**
- 基础核心：卷腹（上腹，抬 30–40° 不拽头）、仰卧举腿（下腹/骨盆后倾）、侧/屈腿卷腹（侧前）、
  侧卧起/侧卧并腿（腰方肌）、俯卧挺身（背肌）；稳定性：俯桥/侧桥/仰桥（臀桥）静力支撑。
- 专项核心：在核心稳定前提下模拟跑步——平板支撑交替屈腿、俯桥提膝后摆腿、侧桥单侧模拟跑、
  单腿臀桥、臀桥接提膝。**动作模式要高度接近跑步，而非死做平板。**

**臀中肌（跑步稳定"关键先生"，发力靠臀大肌、稳定靠臀中肌）**
- 为何关键：向上连骨盆、向下连大腿；弱→骨盆上下晃、腿内收内旋（膝内扣/X 腿）→髌骨轨迹异常
  →膝前痛/膝外侧痛。膝痛患者臀中肌较健康人弱约 20%–35%。
- 训练：髋部提拉、单腿外摆、单腿浅蹲后外摆、侧卧腿外摆、侧卧贝壳式、跪姿侧桥接上摆腿、
  俯卧四点支撑腿外摆（全程保持骨盆中立、脚尖朝前）。

**下肢力量（从一般→准专项→专项，越往后越接近跑步单腿交替发力）**
- 初级（一般）：四分之一蹲、半蹲、深蹲、宽蹲（平衡髌骨轨迹）、原地弓箭步、臀桥、蹲跳。
- 中级（准专项）：弓箭步、单腿上训练凳、保加利亚剪蹲、单腿硬拉、单腿臀桥、弓箭步跳。
- 高级（专项）：单腿上凳接高抬腿、平板支撑交替屈腿、侧桥单侧模拟跑、单腿硬拉接提膝、
  弓箭步接高抬腿跳起。**下蹲只是基础，不替代跑步专项力量。**

**小腿（动力链末端推进器 + 缓冲稳定器，多数人只练提踵不够）**
- 力量：勾脚（胫骨前肌，与提踵拮抗，防崴脚）、提踵（单脚优先）。
- 稳定：睁眼单脚站 60s→抱胸 45s→闭眼抱胸 30s。
- 缓冲：训练凳单腿前脚掌下落，落地越轻越好。
- 爆发力：单脚原地跳、双脚/单脚前后跳（脚跟少触地，缩短触地时间）、跳绳。

**爆发力（plyometric，挖掘肌腱弹性势能→提高跑步经济性）**
- 动作：弓箭步跳、弓箭步接高抬腿跳、开合跳、反弓跳、台阶交替跳。
- 规则：唯快不破（拉长-缩短衔接要短）；在力量训练**之前**或跑前激活做；每组 8–12 次×2 组，
  每周 1–2 次；充分热身后做，防拉伤。

**跑者如何练力量**：动作规范第一；做 12–16 次重复的肌肉耐力练习（贴合跑步需求）；
**力量日与跑步日分开**（耐力与力量相互拮抗）；不必追求大重量。

### 4. 伤痛处理通用原则 + 按部位速查
**通用原则（治标→治本顺序）**
1. 先判断急性 vs 慢性：急性拉伤/扭伤→停跑完全休息 1–2 周；慢性劳损（跑者膝）→不必全停，
   减至"跑时和跑后不痛"为度，跑中痛就果断停。
2. 治标三件套：休息（减量）、治疗（非处方消炎镇痛，急性扭伤 48h 内禁用红花油类活血药）、
   防护（护具/肌贴）。
3. 治本三法宝（反复出现伤痛的根本解法）：**放松肌肉（拉+滚+揉，泡沫滚筒/网球）、加强力量
   （尤其臀中肌+髋+躯干）、改进跑姿（前掌/全脚掌外侧着地、缩小步幅、膝微屈）**。
4. 膝痛跑者康复训练要点：避免大负重大幅度膝屈伸（深蹲/弓箭步/低位靠墙静蹲）；改用高位靠墙
   静蹲、仰卧直腿抬高（16–20×2–3）、单腿硬拉、臀桥（12–16×2），加臀中肌与核心训练。
5. 自测肌肉紧张度（<10cm 脚跟不离地勾脚距墙=小腿紧；跷二郎腿大腿无法重叠=臀肌紧；髂胫束紧=
   大腿向外打开）发现紧张就拉伸放松。

**按部位速查表（痛位 → 根因 → 对策）**
| 痛位 | 常见诊断 | 根因 | 对策（治本） |
|------|----------|------|--------------|
| 膝前（定位模糊、上下楼/下楼痛） | 髌股关节综合征（跑者膝） | 下肢力线/力线异常、肌肉紧、力量差、跑姿错、跑量过大 | 加强臀中肌+股四头/腘绳肌均衡+核心；拉伸放松大腿前/外侧/臀；改进着地（全脚掌外侧、缩小步幅、膝微屈）；髌骨包裹护具 |
| 膝外侧 | 髂胫束摩擦综合征 | 臀中肌弱→髂胫束代偿紧张；髂胫束紧 | 泡沫轴滚髂胫束+拉伸；强化臀中肌；髂胫束支持带护具 |
| 膝内侧 | 鹅足腱滑囊炎 | 内侧肌群紧张/力量失衡 | 放松大腿内侧/后侧，加强臀中肌与核心 |
| 膝后 | 腘绳肌止点拉伤 | 大腿后群柔韧差/离心不足 | 腘绳肌拉伸+单腿硬拉；循序渐进增量 |
| 膝下方 | 髌尖末端病 | 髌腱负荷过大/离心不足 | 离心提踵、减少跳跃冲击，渐进负荷 |
| 小腿（胫骨内后中下段、按压痛） | 胫骨内侧应力综合征（MTSS） | 缓震不足、小腿前后肌力失衡、胫骨前肌无力、新手增量快 | 放松小腿前/后/外侧肌；勾脚训练+提踵离心（快起慢落 6–8s）；足弓训练（抓毛巾）；单腿落地稳定练习 |
| 跟腱（腱体 止点上方 2–6cm，起止/活动后痛） | 跟腱病（非炎性，过度使用） | 跟腱过紧（勾脚不足）、绷脚力弱、扁平足力线异常 | 提踵离心（核心康复，不忍痛）；4 动作拉伸各 4×30s；勾脚练习；跑前立踵/勾脚走热身；足矫形器（力线异常者） |
| 足底（晨起下床跟骨内侧剧痛、久坐后起步痛） | 足底筋膜炎（劳损非炎症） | 勾脚不足/小腿紧、肥胖、久站、突增跑量、扁平足/高足弓 | 定制矫形鞋垫（最佳）；拉伸小腿+足底（踩网球/掰脚趾）；夜间夹板（>6 月者）；加强小腿脚踝力量 |
| 崴脚/脚踝不稳 | 踝关节扭伤后遗不稳 | 小腿肌肉弱/疲劳、内外翻活动异常 | 勾脚+提踵+单脚站立稳定训练（睁眼→闭眼）；平衡训练；必要时护踝 |

### 5. 马拉松参赛与恢复
- **赛前减量**：仅针对系统训练 6 个月以上的高水平/资深跑者；多数大众跑者本身跑量不足，**不需
  减量，反而应增加马拉松配速跑（M 配速，40–110min，储备心率 75–84%，单次要 ≤ 周跑量 15–20%）**。
  赛前 2–3 周**不宜**做 30km 拉练（距赛 >1 月才有必要）；赛前 3–4 周最佳训练 = M 配速跑。
- **参赛指南**：前一天检查装备、跑 30–45min 保持状态即可、晚餐七八成饱、22 点前睡；当天早餐与
  发枪间隔 ≥1.5–2h、三少一多（产气少/体积小/油纤少/热量多）；发枪压住速度按自己配速跑；**逢站
  必进、少量多次**（每次 100–200ml，首小时补水、之后补电解质）；10km 后补糖、每 8–10km 能量胶
  （配 200–300ml 水稀释）；按平稳配速/心率跑，先快后慢或跑走结合亦可；终点前勿猛冲，冲过终点后
  慢跑/快走缓冲。
- **按心率跑马（优先于配速）**：心率与配速冲突时降速保心率。体验型 65–78% 最大心率；有成绩追求
  79–84%（M 配速区）；不建议长时间 >85%（末 5–8km 因"心率漂移"略超可接受）。资深者可适当放宽。
- **赛中紧急**：抽筋=肌肉反向持续牵拉（本质是能力/疲劳问题，非单纯缺盐）；岔气=降速深呼吸/按压
  痛点；撞墙=降速跑走结合+多吃补给。**一路吃喝补不回丢失电解质（全马可丢 ~11g 盐，补给仅补 ~3g），
  补盐丸心理作用 > 实际，扎训练才是根本。**
- **赛后恢复**：冲线后**勿立即拉伸**（肌肉半痉挛，立即拉易诱发抽筋）——先慢跑 15–20min 或步行
  30–60min；半小时后拉伸；尽早补糖补水（尿色转清=水合完成）；45–60min 后温水澡（冬 ≤42℃/夏 37℃，
  ≤20min）；泡沫滚筒/按摩；充足睡眠；可冰水泡脚 10–15min、穿压缩袜 24h。**至少休 1–2 周再恢复轻量
  训练，2 周轻量过渡**；停跑 6–7 天 VO2max 仅降 1–3%，放心休。
- **排酸跑是误区**：乳酸运动结束 30min 内即清除完毕；次日酸痛是延迟性肌肉酸痛（肌肉细微损伤），
  应休息而非排酸跑，强行跑反而延迟修复。资深者次日微酸消失是自然恢复，非排酸之功。

## 决策规则
- IF 步频 <170 或着地声"重/跺脚" → 优先加快步频至 180、缩小步幅、着地点靠近重心、膝微屈，而非改着地部位。
- IF 准备参赛 → 无 15km 经历不报半马、无 30km 经历不报全马（信封效应）。
- IF 近期周跑量 ÷ 平时周跑量 >1.5 → 受伤风险高危，停止加量（>1.6 尤甚）。
- IF 膝痛反复 → 先查臀中肌力量 + 髋/躯干稳定性，强化臀中肌与核心常比"治膝"更治本。
- IF 小腿/跟腱/足底伤痛 → 做"勾脚幅度"自测；紧张则拉伸+提踵离心+勾脚训练+足弓训练。
- IF 跑者问"跑步掉肌肉" → 纠正：跑步改变肌肉类型而非掉肌肉，需 12–16 次重复力量+与跑步分日。
- IF 赛前大众跑者 → 不减量，加 M 配速跑；IF 系统训练半年以上高手 → 赛前减量（减总量保配速）。
- IF 跑马配速与心率冲突 → 降速保心率（控 ≤85% 最大心率，末段漂移除外）。
- IF 跑马后次日 → 不排酸跑，休息；肌肉细微损伤需 1–2 周自然恢复。

## 反模式（不要做）
- 大步幅 + 慢步频 + 脚跟远靠前 + 膝伸直锁死的"甩小腿跑"（最伤膝）。
- 盲目模仿前脚掌着地却小腿/脚踝力量不足 → 膝痛减了，换来足底筋膜炎/跟腱炎/MTSS（更有效率的
  着地需匹配更强肌肉）。
- 膝痛时仍做大负重深蹲/弓箭步/低位靠墙静蹲（增加关节面压力，加剧痛）；应以高位静蹲、直腿抬高、
  单腿硬拉、臀桥替代。
- 一次过量（平时 10km 贸然全马）或跑量短期猛增（比值 >1.5）→ 撑破信封，不可逆损伤。
- 带伤硬练、用护具/药物掩盖疼痛继续加量 → 陷入"跑-伤-治-再伤"循环。
- 跑马后立刻拉伸（半痉挛肌肉牵张反射诱发抽筋）；赛后做"排酸跑"（无酸可排，反延修复）。
- 把 220−年龄 当真实最大心率设手表（误差大，强度误判）；用盐丸/补给当"防抽筋神器"（根因是能力）。
- 力量与跑步同日做（耐力↔力量相互拮抗，大众虽影响小但仍建议分日）。

## 速查表（决策用）
- 跑姿：步频 170–180（目标 180）；着地膝角 ~160–163°→下压至 ~136°；躯干前倾 ~15°；摆臂不越中线。
- 力量阶梯：核心（基础+专项）→ 臀中肌（7 动作）→ 下肢（一般→准专项→专项）→ 小腿（力量+稳定+缓冲+爆发力）→ 全身爆发力（每周 1–2 次，力量前做）。
- 训练配速/强度：LSD+尾声冲刺；抗乳酸 89–92%HR/周≤10%/≥20min；间歇 95–100%HR/1:1/总 20–30min；MAF=180−年龄；亚索 800 组时≈完赛时；原生速度=鼻呼吸极限≈50%VO2max。
- 伤痛根因规律：臀中肌弱 → 骨盆/膝不稳 → 膝内扣 → 膝前/外侧痛；组织紧 → 缓冲差 → 劳损。
- 马拉松：大众不减量加 M 配速跑；心率控 ≤85%；补给逢站必进 100–200ml；赛后休 1–2 周，不排酸跑。
- 信封红线：无 30km 不报全马；近期/平时跑量比 >1.5 即高危。
