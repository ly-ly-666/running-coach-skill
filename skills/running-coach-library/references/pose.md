# 姿势跑法（Pose Method of Running）— 蒸馏稿

> 来源：尼古拉斯·罗曼诺夫（Nicholas Romanov）《姿势跑法》。本稿只覆盖
> **代码无法表达的方法论**：三大元素、关键跑步姿势、常见错误与矫正、矫正训练动作、
> 优秀跑步技术的规则。跑步技术本身无法用代码实现，只能作为 AI 教练给跑者的
> 反馈/纠正依据。来源章节映射见文末（section 编号对应 refsrc_pose.txt）。

## 方法论（心智模型）
- **重力是引擎，不是敌人**。跑步前进的动力来自重力，而非腿部肌肉的推蹬。
  好跑者像帆船手利用风力一样，把重力「落下」转成水平速度；对抗重力（推蹬、跨大步）
  只会减速并增加冲击（sec5, sec72.1-2）。
- **跑步 = 无数个「姿势」的连续重复**，技术可被教学与精熟，不是「天生定型」
  （sec5）。一旦模式建立会「过度学习」深烙身体，所以改动作要在赛季结束、对成绩
  期望最低时开始（sec5）。
- **速度 = 步幅 × 步频**。疲劳时步幅会自然缩短，正确应对是「提高步频」而非
  加大步幅；精英后段步幅也会缩短约 20%，靠步频维持速度（sec58）。
- **技术、耐力、心理三支柱共生**。完美技术减少体力消耗与冲击；但下意识自我设限
  （"我跑不快"）会令身体自动减速——用知识填满恐惧的空洞（sec58）。
- **「免费动力」**：重力、肌肉伸缩力、惯性力、科氏力——不靠代谢产能即可运用
  （sec71）。

## 核心流程

### 1. 三大元素（Pose → Fall → Pull）与每步执行清单
每一步都按以下顺序循环；把它当成一次性的「落地—落下—拉起」节拍：

| 阶段 | 动作要点 | 常见偏差（即时纠正） |
|------|----------|----------------------|
| **Pose（关键跑步姿势）** | 脚掌前缘（跖球部）着地，支撑脚在身体重心正下方；膝微弯，身体呈 S 形；另一腿放松、脚跟提起。身体像被压紧的弹簧 | 支撑脚跑到重心前方、腿打直、脚跟先着地 → 回到重心正下方、屈膝 |
| **Fall（落下）** | 从支撑脚踝开始，让身体作为一个整体向前微倾并「自由落下」，靠重力前进。是前倾的"允许"而非主动迈步 | 从腰部前倾、身体后仰、主动迈腿 → 从脚踝前倾、不抵抗重力 |
| **Pull（拉起）** | 支撑脚一到达重心正下方，**用后大腿肌把脚踝垂直向上拉向臀部**离开地面。只此一次收缩（像活塞"点燃"），脚离地即放松 | 推蹬、脚尖蹬地、向前伸腿 → 只向上拉、不蹬不伸 |

**每步检查清单（落地瞬间应一致）**：
1. 着地的是跖球部，不是脚跟；2. 膝关节弯曲；3. 落地点在臀部正下方；
4. 身体从脚踝前倾（肩、臀、踝成一直线）；5. 脚一触地立即向上拉起，停留越短越好；
6. 拉起只用后大腿肌，离地后立刻放松。

### 2. 关键跑步姿势要点
- 维持「关键跑步姿势」：腿始终弯曲，支撑点在跖球部，身体呈 S 形（sec59.1）。
- 前倾从**脚踝**起，肩、臀、踝保持一直线；不要从腰弯（sec71.1-2）。
- 支撑点与体重落在跖球部；后脚跟可轻触，但重量绝不压在脚跟（sec71.4, 71.10）。
- 双脚转换支撑点要快；支撑时间尽量缩短——落地即拉起（sec71.5, 71.7）。
- 脚掌着地时不出力、放松轻巧；不要蹬地，只是向上抬（sec71.8-9）。
- 着地点落在「通过臀与膝的直线之后」（身体正下方偏后），绝不超前（sec71.11-12）。
- 脚踝只上下移动，不前后摆荡；拉起后大腿膝盖放松（sec71.15-16, 71.20）。

### 3. 常见错误与矫正
| 错误 | 表现 | 矫正 |
|------|------|------|
| 太过前跨 / 过度跨步 | 脚掌着地点超过重心前方、脚跟着地、胫前疼痛 | 落地点移到臀部正下方；赤脚草地/沙滩跑建立前掌着地感知（sec60, sec64） |
| 蹬地 / 脚尖推地 | 脚掌触地时向下使力，腾空对抗重力 | 只向上拉、不蹬；用弹力绳/摩托拖曳意象理解"被重力拉着跑"（sec66） |
| 腿尾巴（leg tail） | 后腿在身后伸直、或脚掌拉太高超过臀部水平 | 脚一落地立即向上拉；只靠后大腿肌；前大腿（股四）放松不向前顶（sec61） |
| 后大腿肌用力过度 | 脚离地后持续上拉，腿尾巴、步频变慢 | 脚掌触地瞬间才"点燃"收缩，离地即随惯性放松（sec62） |
| 抬大腿 / 摆荡腿过大 | 大腿向前顶或上抬，空中停留久、重踩 | 用"伙伴身后跑""双手后伸跑"限制摆幅（sec63, sec64） |
| 脚跟着地 | 脚跟先触地、脚掌滞留地面久、抵消推进 | 承认其为错误；赤脚跑、交叉步、小马踮步重建前掌着地（sec64） |
| 垂直震荡 / 弹跳过大 | 上下跳动、下坡加大步幅 | 缩短步幅、重心放低、避免跳；脚掌始终在身体正下方（sec54, sec66） |
| 手臂过度摆动 | 手臂摆太快/太前，分走腿部能量、破坏平衡 | 手臂只用于平衡，自然放松随脚摆动（sec68） |
| 坐姿前倾 / 腰弯 | 从腰部而非脚踝前倾 | 维持踝-臀-肩直线的前倾（sec71） |

### 4. 入门 / 矫正训练动作清单（高阶要点，非计数）
- **小马踮步（pony）**：原地双前掌交替踮步，最小动作、最省力、保平衡；是正确技术地基（sec64.1）。
- **脚掌轻敲地面**：S 形站姿，非支撑脚抬起后放松回原处（始终落在支撑脚旁），练"自然落下而非下踩"（sec61.1）。
- **原地单脚跳跃 / 跳绳单脚跳**：关键跑姿下用最少力快速收缩后大腿肌拉离地面，前掌着地（sec65.2-3）。
- **弓箭步 / 健身球平衡**：站在健身球上维持关键跑姿平衡且放松，暴露细微失衡肌群（sec65.1）。
- **利用支撑点转换前进**：把注意力放"非支撑脚悬空→换支撑脚抬起"，体会脚不施力顺重力落下（sec60）。
- **脚踝绑弹力绳**：绑脚踝（或腰-踝、或双人）强迫脚掌垂直向上拉、落回正下方，并加速拉起（sec61.3, sec64.2）。
- **上坡跑**：缩短步幅、加快步频、只拉不蹬，强化拉起知觉（sec54, sec61.8）。
- **沙滩 / 草地赤脚跑**：不稳定表面迫使前掌轻触、高步频，快速暴露并改掉脚跟/蹬地旧习（sec53, sec64.3-4）。
- **伙伴辅助**：身后跟跑、前方/肩并肩弹力绳、双手后置跑，限制摆幅与腿尾巴（sec61.4-7, sec63, sec64.5）。

### 5. 优秀跑步技术的规则（浓缩）
- 从脚踝整体打直前倾；肩-臀-踝一线；膝始终弯（sec71.1-3）。
- 体重落跖球部；转换支撑点要快；支撑时间越短越好（sec71.4-7）。
- 着地不出力、放松轻巧；不蹬地、不脚尖着地（sec71.8-9, 71.19）。
- 不脚跟着地承重；着地点在臀膝直线之后；重量在跖球部就立即上拉（sec71.10-12）。
- 加速不靠加大步伐/动作幅度，那是结果不是原因（sec71.13）。
- 膝盖大腿不前后摆太远；脚踝不前后摆荡只上下；拉起后大腿膝盖放松（sec71.14-16）。
- 只"抬脚"而非在意跨步与落下；双腿随重力自由落下（sec71.17-18）。
- 手臂自然放松，只为平衡（sec72.21）。
- 核心概念提醒：跑步是姿势的组合；抬脚与费力都和重力有关；自在跑＝让身体自由落下；
  转换支撑点＝垂直向上拉脚掌；拉起完全由后大腿肌完成；坚守「拉起」非「蹬地」（sec72）。

## 决策规则
- IF 纠正跑姿 → 先确认错误在标准前（承认脚跟着地/蹬地是错），再用示范练习重建感知，而非只做技术微调。
- IF 落地姿势不对 → 检查：跖球部着地？膝弯？落点在重心正下方？三者任一不符即回 Pose。
- IF 疲劳后步幅缩短 → 提高步频（≠加大步幅），专注当下动作与重力利用（sec58）。
- IF 想加速 → 提步频、缩支撑时间，而非加大动作幅度/跨步（sec71.13）。
- IF 上坡 → 缩短步幅+加快步频+只拉不蹬；IF 下坡 → 缩步幅、重心放低、不跳、脚掌仍在正下方（sec54）。
- IF 改动作初期 → 在成绩期望最低时练；单次要领跑 ≤1.5km，别一累就退回旧模式（sec5, sec58）。
- IF 小腿发酸（改前掌着地初期）→ 正常，数周消失；膝盖/下背疼痛应减轻（sec64）。
- IF 有伙伴/摄影 → 用慢动作回看落地瞬间是否每次一致，比对"拉起"与"腿尾巴"差异（sec61, sec62）。

## 反模式（不要做）
- 用脚尖/脚掌蹬地推进——你在和重力搏斗，会减速并增冲击（sec66）。
- 向前伸腿、过度跨步、脚跟着地——着地点超前重心，引发胫前疼痛与制动（sec60, sec64）。
- 从腰部前倾或身体后仰——前倾必须从脚踝起，肩臀踝一线（sec71）。
- 后大腿肌持续上拉（腿尾巴）——只在触地瞬间"点燃"一次，离地即放松（sec62）。
- 抬大腿/摆荡腿过大——空中停留久、被迫重踩，加倍后大腿负担（sec63）。
- 加大步幅对抗疲劳——应提步频；加大步伐只会心跳升、肌肉紧、速度降（sec58）。
- 手臂过度摆动冲刺——分走腿部能量、破坏平衡与心理（sec68）。
- 心思飘到未来/处理生活杂事时跑——训练的是"跑得更差"；分神就停（sec58, sec69）。
- 穿厚垫鞋助长脚跟落地——鞋垫只掩饰错误，不纠正技术（sec64）。

## 速查表（决策用）
- 三步循环：Pose（S形、跖球部、膝弯、重心正下）→ Fall（踝前倾、自由落下）→ Pull（后大腿肌垂直上拉向臀、离地即松）。
- 落地四查：前掌着 / 膝弯 / 重心正下 / 即刻上拉。
- 免费动力：重力、伸缩力、惯性、科氏力——顺之，不抗之。
- 加速 = 提步频 + 缩支撑时间；疲劳应对 = 提步频非加大步幅。
- 着地点必须落在臀-膝直线之后；脚跟可轻触但绝不承重。
- 矫正顺序不跳步：感知落下→拉起→支撑点转换；用伙伴/弹力绳/赤脚/摄影放大盲点。
