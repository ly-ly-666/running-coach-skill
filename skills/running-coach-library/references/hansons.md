## 方法论（心智模型）
- **累积疲劳（cumulative fatigue）**：不要靠「一次超长 LSD」制造全部刺激，而是把压力
  **均匀铺在一整周**，让身体持续处于"未完全恢复"的疲劳态，用连续多天中等负荷逼近比赛负荷。
  目标是「**站在起跑线时已彻底恢复**」，也就是训练期游走在"训练充分—过度训练"曲线附近、但不超过它。
- **训练由两类日子构成**：**轻松跑日** + **实质训练（Something of Substance, SOS）日**。
  SOS = 长距离跑、节奏跑、力量跑、速度跑。只要比马拉松慢的配速就是轻松跑。
- **没有"垃圾跑量"**：轻松跑占每周比重最大、最容易被误当填充。它是吸收 SOS 刺激、堆有氧底子的主战场。
- **关键 5 组成部分**：**跑量 · 强度 · 平衡 · 稳定 · 恢复**。任一环节崩坏都会连锁拖垮其余，
  限制为马拉松所需的生理适应。
- **周期加载**：每隔 **4 周**，周里程经轻松跑/节奏跑/长距离累积而小幅提升；身体适应后把压力
  转为进步，赛前最后一次让身体完全恢复、焕然一新地站上起跑线。

## 核心流程

### 1. 训练类型定义与配速规律（本书核心参数）
| 类型 | 是什么 | 配速规律 |
|------|--------|----------|
| **轻松跑 Easy** | 有氧底子、吸收刺激 | 新手比马拉松配速（MP）**慢 74 秒/千米**；进阶者可快些。**慢速轻松跑**比 MP 慢 37 秒/千米（节奏跑后的次日、或轻跑往前两天用） |
| **节奏跑 Tempo** | =**马拉松配速跑（MP）**，贯穿计划数月，模拟比赛、练"内在配速" | 维持 **MP**；也用于赛前演练装备/配速 |
| **力量跑 Strength** | 以比 MP **快 6 秒/千米**的配速跑间歇（接近半马配速），刻意制造厌氧阈压力、积累乳酸，让身体适应乳酸堆积不适 | 目标 MP − 6 秒/km；快跑者的数字接近半马配速，新手介于全马目标配速与半马能力之间 |
| **速度跑 Speed** | 短间歇提高最大摄氧量（VO2max），同时也抬升有氧阈（一箭双雕），耗尽糖原迫使肌肉储存更多糖原 | 接近但 **≤100% VO2max**；约 **5K–10K 比赛配速**；最佳单组 **2–6 分钟** |
| **长距离跑 Long** | 堆耐力、练精神与"撞墙前的坚持"；训练快肌纤维必须靠它（须先让慢肌疲劳） | 约 **MP 附近或略慢**；丹尼尔斯博士研究为 L 跑基础 |

### 2. 一文周结构（马拉松专项期，实质练习在**周二、周四、周日**）
| 日 | 内容 | 性质 |
|----|------|------|
| 周一 | **轻松跑** 8–13 千米 | 恢复（吸收周日 + 备战周二） |
| 周二 | **速度跑 / 力量跑**（间歇；当场次二选一） | SOS（速度/力量） |
| 周三 | **轻松跑** | 恢复（"三明治"分隔两场 SOS） |
| 周四 | **节奏跑（MP）** | SOS（耐力/比赛配速） |
| 周五 | **轻松跑**（节奏跑后的缓冲，防过度训练） | 恢复 |
| 周六 | **轻松跑** | 恢复 |
| 周日 | **长距离跑**（配速/里程按能力与感觉调） | SOS（耐力顶） |
- 跑量铺法：**周六/周日做大跑量**（周末时间有保障），其余大致均分到工作日；工作日常为相对高强度，
  正是累积疲劳理念——而非传统计划把强度挤在周末。
- 周内即时微调（舒适依据）：如周日 L 跑、周二练力量，则周一如感到累就跑轻些，确保周二有质量。

### 3. 速度/力量课的"阶梯"结构
- **速度跑**：从较短重复起（**10–12 组 400 米**），渐长至 **4 组 1200 米 / 3 组 1600 米**；
  到阶梯顶端后身体更轻松、发展更好。运动生理学家共识：**最佳间歇时间 2–6 分钟**——<2 分钟对
  最大摄氧量压力不足。
- **力量跑**：同样以马拉松/半马目标配速找表跑间歇（例：5K 目标 15:30 / 10K 32:30 → 1200m 重复配速约 3:42）。
  速度快的跑者数字已接近"MP−6 秒"，初跑者略慢于此。

### 4. 长跑距离封顶（机会窗口）
- **比约 5:32 每千米更慢的长跑，不应超过 32 千米**；超出则超出专家学者推荐的"机会窗口"。
- L 跑目的在于让双腿在**已有疲劳**下继续工作——**模拟的是马拉松"后半程 26 千米"而非"前半程"**。
- 跑量分级参考（周跑量）：新手 24–40 km；半马选手 48–64 km；为全马准备者可常规提到 80–128 km，
  在有底子的跑者里加到全马的 2–3 倍（80–120 km）可行。

### 5. 恢复、赛前与赛后
- **不完全恢复是训练组成部分**：疲劳积累需要"局部调理"而非彻底躺休——大强度后轻松跑以燃脂为主、
  帮助回补碳水/糖原、不丢有氧适能。
- 大强度课后肌肉糖原耗尽：约需 **72 小时**才能补满（单次约 2 小时跑最多消耗 50% 糖原），
  因此训练循环中段不宜天天大强度。
- **赛后**：首马/大强度赛后**先完全休息两周**（不跑步，让脚彻底离地），可做轻抗阻或单车交叉训练保持习惯；
  之后回到 **20–30 分钟慢跑**开始渐进恢复。
- **补充/营养**：以碳水为能量主线，靠线粒体密度/体积提升脂肪利用与有氧能力；糖原储备决定耐受力。

## 决策规则
- IF 设计马拉松周期且跑者能每周 6 跑 → 用「3 个 SOS 日（Speed/Strength + Tempo + Long）+ 3 轻松」，
  SOS 固化在周二/周四/周日。
- IF 给轻松跑定配速 → 新手用 MP−74 秒/km；节奏跑次日/轻跑往前数两天用 MP−37 秒/km。
- IF 排力量课 → 间歇配速 = MP−6 秒/km（近半马配速），不是跑更慢的"有氧力量"。
- IF 排速度课 → 单组落在 2–6 分钟、强度 ≤100% VO2max（约 5K–10K 比赛配速），阶梯 400→1600 米。
- IF 设计长跑 → 配速若慢于≈5:32/km，封顶 32 km；整体长跑 ≤ 周跑量约 30%。
- IF 减量/赛前 → 每隔 4 周小幅加量后，最后约 3 周降总量、保质量配速强度。
- IF 赛前观感 → 更看重"慢慢积累的疲劳 + 赛前彻底恢复"，而非追求某次超长距离的自我证明。

## 反模式（不要做）
- 照搬"一次 32km+ 超长 LSD"当唯一刺激——汉森用整周累积疲劳替代单次超长。
- 把轻松跑当垃圾量跑太快——轻松日不轻松就失去吸收 SOS 刺激、堆有氧底子的作用。
- 力量课也跑"轻松有氧配速"——汉森的力量课是**比 MP 快 6 秒/km** 的间歇，刻意堆乳酸。
- 长跑无限加长到 35–40km——破坏恢复、挤占下周质量课。
- 大强度后排"彻底躺休"——应做低强度轻松跑回补糖原作主动恢复。
- RSS 一次减量就把强度也砍光——减量减量不减质、留比赛配速。

## 速查表（决策用）
- 一周：Mon 轻松(8–13k) · Tue **速度/力量**(间歇) · Wed 轻松 · Thu **节奏(MP)** · Fri 轻松 · Sat 轻松 · Sun **长距离**。
- 配速公式：轻松=MP−74s/km（新手）；慢速轻松=MP−37s/km；力量=MP−6s/km（近半马）；节奏=MP；速度≈5K–10K 比赛配。
- 速度阶梯：10–12×400m → 4×1200m / 3×1600m；单组 2–6 分钟。
- 长跑：慢于 ≈5:32/km 时封顶 32km；≤ 周跑量 30%。
- 累积疲劳五要素：跑量 · 强度 · 平衡 · 稳定 · 恢复；每隔 4 周小幅加量，赛前约 3 周降量保质。
