## 方法论（心智模型）
- **渐进超负荷（progressive overload）**：体能提升的唯一根本——负荷（重量/次数/密度/强度）
  须随适应渐进增加，否则停滞。负荷是改变力量与肌肉大小的主要刺激。
- **专项性（SAID）**：力量训练强调**基础性 + 普适性**——所有运动项目都先需要基础力量，
  再按专项需求做针对性增强；训练适应高度特异于动作模式、收缩速度、肌群与能量系统。
- **大小原则（运动单位募集）**：募集顺序从慢肌(I型)→快肌(II型)固定不变。**轻负荷多次重复**主要
  激活 I 型纤维（利于肌肉耐力）；**大负荷**才能募集 II 型纤维（最大力量与肌肥大）。研究显示
  很轻负荷（20–28 RM）不引起 I 型纤维增长，而 9–11 RM 或 3–5 RM 可增加全部纤维类型横断面。
- **恢复是处方的一部分**：适应发生在恢复期；周期性改变运动量可提供休息与恢复时间。

## 核心流程

### 1. 训练目标 → 负荷参数表（核心处方表，OCR 原文数据）
| 目标 | 强度 %1RM | 次数 | 组数 | 组间休息 | 备注 |
|------|-----------|------|------|----------|------|
| 最大力量 Maximum Strength | **85–95%**（主流认为 85% 效果最佳） | **2–6** | **2–5** | **2–5 min** | 负荷越接近 1RM 适应越强 |
| 爆发力 Power | 轻-中（含快速伸缩/增强式、药球、壶铃） | 低次数、最大速度 | 3–5 | 2–5 min 或较长 | 强调最大动作速度与神经驱动 |
| 肌肉肥大 Hypertrophy | ~67–85% | 6–12 | 3–6 | 30s–1.5 min | 肌肉紧张时间足、中速节奏 |
| 肌肉耐力 Muscular Endurance | <67%（轻） | >12（如 12–15） | 2–3 | <30s 或短 | 短休维持代谢压力 |

- **≤10 RM 负荷**：用于较重的锻炼项目，重在增大肌肉围度与增强肌力。
- **循环训练（circuit）**：每组包含 10–12 种不同动作、连续完成、几乎无休息，做 1–3 循环；
  低负荷（**40–60% 1RM**）、多次重复（12–15 次）或定时（如 30 秒）。好处：单次内同时增力量与心血管。
- **初学者负荷路径**：第 **1 个月用 60–70% 1RM、8–12 次**（先学技术，别上大重量）；第 2–3 个月
  增加组数并稍加大至约 **80% 1RM**。找到适用负荷往往需 2–3 次训练试错。

### 2. 练习类型：主要 vs 辅助
- **主要练习（primary）**：锻炼主动肌（负责运动主要动作），例：深蹲、杠铃卧推、悬垂高翻。
- **辅助练习（assistance）**：训练辅助主动肌的肌群，例：绳索肱三头肌伸展、哑铃肱二头肌弯举。
- **多关节 vs 单关节**：多关节练习（深蹲、高翻）激活肌肉多、神经/代谢/激素反应高，**大多数训练应围绕
  多关节进行**；单关节（弯举）作补充。

### 3. 单次训练课动作排序原则（OCR 原文完整列表）
1. 先锻炼**大块肌群**，再锻炼小肌群。
2. 先进行**多关节运动**，再进行单关节运动。
3. 全身环节中**交替进行推/拉练习**。
4. 全身环节中**交替上肢/下肢**练习。
5. 先练**弱侧**，再练优势侧。
6. 进行基础力量/单关节之前先做**奥林匹克举**（高翻/抓举等）。
7. **爆发力训练优先**。
8. 同肌群连续训练时**先高强度、后低强度**。
- 理由：训练初期最不疲劳、神经驱动最足，先把高耗能/高神经动作做完，避免疲劳后大重量动作变形。
- 跑者专项：把"单腿"动作（单腿硬拉、保加利亚剪蹲、单腿臀桥）置于主要复合动作后作专项补充。

### 4. 周期化模式（与 periodization.md 衔接）
- **线性周期（classic/linear）**：数周/数月内强度↑、次数↓，适合打基础期、新手。
- **非线性/波动周期（DUP）**：一周内不同天用不同负荷/次数组合（如 周一 5RM、周三 10RM、周五 15RM），
  适合进阶者维持多能力、避免平台。周期性计划（经典或非线性）对优化效果至关重要。
- **选择**：新手/基础 → 线性；有经验 → 波动/非线性避免停滞。

### 5. 进阶与技巧
- 加量前提：能**用良好技术完成目标次数**；负荷进阶幅度 —— 新手可稍快，老手小幅渐进，避免关节/肌腱过载。
- 呼吸：训练全程保持正常呼吸，任何过程**不要屏住呼吸**。
- 长期做相同训练会进度停滞、变无聊或导致过度训练（肌肉性能减退）——需周期性变化。

## 决策规则
- IF 目标=最大力量 → **85–95% 1RM、2–6 次、2–5 组、组间休 2–5 min**。
- IF 目标=爆发 → 快速伸缩/药球/壶铃等增强式、低次数最大速度、短组 + 充分休息。
- IF 目标=肌肥大 → 67–85% 1RM、6–12 次、延长时间、短-中休息。
- IF 目标=肌肉耐力 → <67% 1RM、>12 次、2–3 组、短休息（或循环训练 40–60%）。
- IF 跑者实用力量 → 主练最大力量神经驱动 + 12–16 次耐力（轻-中负荷补耐力），避免纯肥大大重量。
- IF 初学者 → 首月 60–70% 1RM、8–12 次打技术底子，再渐进到 80%。
- IF 排课顺序 → 爆发/奥举 → 多关节复合大重量 → 单关节辅助 → 核心；弱侧与上肢下肢推拉合理交替。
- IF 想跑得快 → 以基础力量打底 + 专项单腿/爆发补充（肩 跑步日分开）。
- IF 需同时练耐力与力量 → 用循环训练（低负荷多次、短间歇）或把耐力量课与跑日错开。

## 反模式（不要做）
- 把孤立小肌群（弯举）排在深蹲/硬拉前——神经疲劳后大重量动作变形、易伤。
- 只练肥大（8–12 次中重量）当作"跑者力量"——跑者要神经力量+耐力，非肌肥大。
- 长期固定同一处方——平台/停滞/过度训练；变化刺激但保留专项性。
- 负荷(重量)加太快、技术还没稳定就加重——肌腱/关节跟不上肌肉，易过劳。
- 屏住呼吸做大重量——破坏支撑与安全；全程保持呼吸。
- 初学者一上来就用 >80% 1RM ——先学技术，从 60–70% 起步。

## 速查表（决策用）
- 处方：力量 85–95% 1RM/2–6 次/2–5 组/休 2–5 min；肥大 67–85%/6–12 次/短-中休；
  耐力 <67%/>12 次/短休；循环 40–60%/12–15 次或 30s×1–3 循环。
- 初学者：首月 60–70%×8–12 → 渐至 80%。
- 课顺序：爆发/奥举 → 多关节 → 单关节 → 核心；大肌群→小肌群、弱侧→优势侧、推拉/上下肢交替。
- 周期：新手线性、进阶 DUP；跑者力量+耐力(12–16 次)、单腿专项、与跑日错开。
